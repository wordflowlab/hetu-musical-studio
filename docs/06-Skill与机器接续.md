# Skill与机器接续

包内hetu-musical-studio由河图动态发现，不创建Codex插件、独立MCP服务器或客户端工具名。安装和启用后重新读取活动包摘要、capabilities与skills.read；旧能力绑定不得继续使用。业务无需启动桌面。

默认旅程：读取固定故事与歌词依据 → 场景和戏剧目标 → 对白及演唱分工 → 主题与再现 → 比较编排及估时 → 固定排练手记 → 返工复核 → 音乐剧本与后续制作。先读已有工程、固定作品及意见，不新建另一份演示工程替代接续。方法由Skill维护，确定性规则由专业后端执行。

段落区分对白、歌曲与过渡，歌曲有明确演唱者、逐行分工、戏剧目标及整数节拍；多人同唱通过同一明确节拍位置表达，不按行数相加。节拍单位为四分音符的960ticks，估时用整数有理数与明确BPM；未知BPM或对白估时保留未知。编排按独立出场记录，可重复同一段落。主题再现固定原段与回归段的组合摘要，反序或未出现原段明确警告；不把相似词项自动认定为再现。排练保存完整使用快照，记录仅为提交者声明。正式歌词资料与乐谱可用固定来源引用，专业段落不替代Owner正文。

每阶段保存并回读固定修订，create_handoff记录依据、目标与未解决问题。其他插件根据实际安装能力独立发现，通过固定专业引用组合。未知先回读，正文采纳、定稿、内容外发与费用按作者确切决定执行。

SKILL.md作为精炼方法入口，references/workflows.md提供专业方法与反例，operations.md从正式清单生成。专业清单由本仓库维护，宿主40只导航动态入口。
