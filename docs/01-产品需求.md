# 产品需求

## 背景与推导

一首完整歌词不能解释角色为什么在此刻唱，也不能保证重唱、主题再现和对白衔接推动了剧情。音乐剧同时有戏剧顺序和音乐节拍。工程保留每次出场、演唱分工与固定排练，Agent处理戏剧创作，作者判断节奏与表达。

生成成本和等待时间会变化，但固定作品、历史依据、具体意见与连续审阅仍需长期积累。固定工程避免让模型每轮重建结构；结构化数据与多种阅读方式共用同一专业成果。插件按需安装，让作者提出目标、Agent操作工程、作者在适合的工作面阅读和选择。

## 定义与首版

音乐剧工坊是河图洛书JS／TS专业插件。把对白、歌曲段落、演唱角色、主题再现和排练手记组织成可继续改写的音乐剧。用户包括独立作者、编辑与外部Agent。默认旅程：读取固定故事与歌词依据 → 场景和戏剧目标 → 对白及演唱分工 → 主题与再现 → 比较编排及估时 → 固定排练手记 → 返工复核 → 音乐剧本与后续制作。

首版包含完整专业维护、准确来源回读、专业方案、固定意见、确定性检查和改稿影响、上下文、固定交接、JSON／Markdown／HTML工程及专业阅读本。功能必须经机器入口执行，作者可以自然语言提出目标，也保留人工优化入口。

## 边界

歌词工坊拥有歌词精修与试听映射，舞台排演拥有部门提示调用，本包拥有戏剧与音乐段落的编排和再现关系。作曲、演唱合成、录音与现场执行由明确外部工具承担；不输出假声音或伪造真人排练。正文、正式设定、素材、采纳与定稿由宿主和作者掌握，不另建数据库、模型渠道或内部Agent。

成功以真实创作、审阅、返工及下一轮接续为准，安装、动作数或文件存在都不足以代表完成。开发与验收状态只由08维护。
