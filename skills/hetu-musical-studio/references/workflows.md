# 创作流程与反例

把旧站来信改成对白、双人唱段和尾声再现。两人从同一节拍进入，比较再现前后两个编排，保存排练手记，再改一个唱段并复核旧编排。

段落区分对白、歌曲与过渡，歌曲有明确演唱者、逐行分工、戏剧目标及整数节拍；多人同唱通过同一明确节拍位置表达，不按行数相加。节拍单位为四分音符的960ticks，估时用整数有理数与明确BPM；未知BPM或对白估时保留未知。编排按独立出场记录，可重复同一段落。主题再现固定原段与回归段的组合摘要，反序或未出现原段明确警告；不把相似词项自动认定为再现。排练保存完整使用快照，记录仅为提交者声明。正式歌词资料与乐谱可用固定来源引用，专业段落不替代Owner正文。

歌词工坊拥有歌词精修与试听映射，舞台排演拥有部门提示调用，本包拥有戏剧与音乐段落的编排和再现关系。作曲、演唱合成、录音与现场执行由明确外部工具承担；不输出假声音或伪造真人排练。

## 固定接续

读取已有成果及全部必要来源，明确未读范围。新意见固定具体目标摘要，旧意见不能默套新稿；返工后通过实际依据动作重新固定并回读。create_handoff返回BasisRef，不是SourceRef；通过公开资料任务保存包含Owner、对象、修订、sha256及专业内容的派生快照，下游任务固定原资料与派生快照并完整回读。不同作品分别获权，旧修订和未知操作保持原义。

OpenSheetMusicDisplay区分乐谱、演奏时间和显示，Trelby提供剧本结构参考。本包采用明确960ticks及整数BPM，不嵌入完整制谱引擎、不复制GPL代码或宣称MusicXML完整兼容。
